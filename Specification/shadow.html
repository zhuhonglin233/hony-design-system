design code 设计规范
阴影
阴影是设计系统中重要的视觉元素，用于创建层次感和深度，增强用户界面的立体感。合理的阴影使用可以提升界面的视觉效果，使元素之间的关系更加清晰。
阴影设计
分层
通过阴影的不同层级，创建界面元素的视觉层次感，使界面更加立体和有深度。
层级 名称 场景 CSS 预览
Level 0 无阴影 默认状态、扁平化设计 box-shadow: none;
Level 1 轻微阴影 卡片、基础组件 box-shadow: 0 1px 2px 0 rgba(0, 0, 0, 0.05);
Level 2 中等阴影 弹窗、下拉菜单 box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.1), 0 2px 4px -1px rgba(0, 0, 0, 0.06);
Level 3 强烈阴影 模态框、对话框 box-shadow: 0 10px 15px -3px rgba(0, 0, 0, 0.1), 0 4px 6px -2px rgba(0, 0, 0, 0.05);
Level 4 深度阴影 悬浮元素、特殊组件 box-shadow: 0 20px 25px -5px rgba(0, 0, 0, 0.1), 0 10px 10px -5px rgba(0, 0, 0, 0.04);
