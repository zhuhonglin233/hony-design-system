# 动态组件系统使用说明

## 概述
这个系统允许你将侧边栏和顶部导航抽取成单独的组件文件，以后只需要修改一份代码就可以应用到所有页面。

## 文件结构
```
website-project/
├── overall/
│   └── components/
│       ├── navbar.html                   # 顶部导航组件（通用）
│       ├── sidebar-desktop.html          # 桌面端组件侧边栏
│       ├── sidebar-specification.html    # 设计规范侧边栏
│       └── 使用说明.md                  # 本文档
├── desktop/
│   └── 你的页面.html
└── Specification/
    └── 你的页面.html
```

## 如何使用

### 1. 在 HTML 页面中添加容器
将原来的导航和侧边栏代码替换为以下容器：

```html
<!-- 原来的 <nav class="navbar"> 部分 -->
<div id="navbar-container"></div>

<!-- 原来的 <div class="side-nav"> 部分 -->
<div id="sidebar-container"></div>
```

### 2. 确保引入了 common.js
```html
<script src="../overall/js/common.js"></script>
```

### 3. 完成！
就这么简单！组件会自动根据页面位置加载对应的侧边栏：
- 桌面端页面会自动加载 `sidebar-desktop.html`
- 设计规范页面会自动加载 `sidebar-specification.html`

## 示例

### 修改前（旧方式）
```html
<body>
    <div class="background-decoration"></div>
    <div class="page-container">
        <!-- 导航栏 -->
        <nav class="navbar">
            <div class="navbar-content">
                <!-- 几百行的导航代码... -->
            </div>
        </nav>
        
        <!-- 主内容区域 -->
        <div class="main-content">
            <!-- 左侧导航 -->
            <div class="side-nav">
                <!-- 几百行的侧边栏代码... -->
            </div>
            
            <!-- 右侧内容 -->
            <div class="content-area">
                <!-- 页面内容 -->
            </div>
        </div>
    </div>
</body>
```

### 修改后（新方式）
```html
<body>
    <div class="background-decoration"></div>
    <div class="page-container">
        <!-- 动态加载的导航栏 -->
        <div id="navbar-container"></div>
        
        <!-- 主内容区域 -->
        <div class="main-content">
            <!-- 动态加载的侧边栏 -->
            <div id="sidebar-container"></div>
            
            <!-- 右侧内容 -->
            <div class="content-area">
                <!-- 页面内容 -->
            </div>
        </div>
    </div>
</body>
```

## 优势

1. **易于维护** - 修改侧边栏只需要改一个文件
2. **代码复用** - 所有页面共享同一份导航代码
3. **减少错误** - 避免多处修改导致的不一致
4. **自动高亮** - 系统会自动根据当前页面高亮对应的菜单项
5. **智能识别** - 自动根据页面位置加载对应的侧边栏

## 注意事项

- 确保你的 HTML 页面中已经引入了 `common.js`
- 容器的 ID 必须是 `navbar-container` 和 `sidebar-container`
- 由于使用了 fetch API，请确保通过 HTTP 服务器访问页面（不是直接打开本地文件）

## 如何添加新菜单项

根据你要修改的侧边栏类型选择对应的文件：

- **桌面端组件侧边栏**: 修改 `overall/components/sidebar-desktop.html`
- **设计规范侧边栏**: 修改 `overall/components/sidebar-specification.html`
- **顶部导航**: 修改 `overall/components/navbar.html`

修改后，所有使用对应组件的页面都会自动更新！
