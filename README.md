# Hony Design System

个人UI组件库，包含常用的UI组件和设计规范。

## 技术栈

- HTML
- CSS
- JavaScript

## 功能特性

- 响应式设计
- 深色/浅色模式切换
- 丰富的UI组件
- 完整的设计规范

## 快速开始

```bash
# 克隆仓库
git clone https://gitee.com/hony-zhu/hony-design-system.git

# 进入项目目录
cd hony-design-system

# 启动本地服务器
python -m http.server 8000
```

## 目录结构

```
.
├── desktop/          # 桌面端组件和页面
├── mobile/           # 移动端组件
├── overall/          # 全局样式和工具
├── Specification/    # 设计规范文档
└── index.html        # 首页
```
